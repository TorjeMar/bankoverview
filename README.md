# Open Banking

A personal finance dashboard project using the Enable Banking API.

The backend lives in [`backend/`](backend/README.md) — see its README for
setup, configuration, running the API, and the current endpoint list.

## Layout

```text
.
├── backend       # FastAPI app (see backend/README.md)
├── secrets       # Enable Banking private key (gitignored)
└── docker-compose.yml   # local Postgres
```

There is no frontend yet.
